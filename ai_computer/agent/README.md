# aicomputer Python package

Local helpers installed into `~/.aicomputer/venv` by `scripts/05-install-agent-runtime.sh`.

```bash
aicomputer doctor
aicomputer chrome start|status
aicomputer inbox
aicomputer reels prepare|status|confirm|abort
```

Development install:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```
